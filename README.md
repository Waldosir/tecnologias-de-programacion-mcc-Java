# Proyectos de Tecnologías de la programación

Este es el repositorio de proyectos en Java de Tecnologías de la programación de la Maestría en Ciencias Computacionales

Se realizaron distintos proyectos:
- ElJuegoDeLaVida: simulación matemática frente a un conjunto de reglas que afectan casillas y épocas
- ElJuegoDeLaVidaNew: Lo mismo que ELJuegoDeLaVida, pero con correcciones realizadas.
- JuegoBarajaBlackJack: Simulación del juego de BlackJack o 21, con crupier y una lista de jugadores
- Buscaminas: Videojuego buscaminas con puntaje.
- BusquedaUsuarios: TRabajo con registro de usuarios y libros
- ColeccionesMLP: Proyecto en la que se realiza un pseudocódigo para ejecutar código real.
- TareaRecursividad: Tarea en donde se utiliza recursividad en distintos ejercicios en clase
- Pruebas: Pruebas con la librería fuzzy logic
